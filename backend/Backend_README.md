

CareConnect Backend

Overview

This folder contains the backend materials for CareConnect, a mental health support Progressive Web Application (PWA) developed for students at the University of Lusaka (UNILUS).

Technology Stack

	•	Java
	•	Spring Boot
	•	Spring Boot REST API
	•	PostgreSQL
	•	Git and GitHub for version control

Purpose

The backend handles the application’s business logic, database operations, API endpoints, authentication, and authorization. It connects the frontend to the database and supports the platform’s student wellbeing check-ins, counselling services, appointment booking, educational resources, and restricted therapy chat.

Development

This backend is being developed collaboratively by the CareConnect team. All contributors should coordinate their changes through the shared GitHub repository and follow the agreed project structure.

Status

Backend development is in progress.
